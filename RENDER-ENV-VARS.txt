🔹 Name: FIREBASE_SERVICE_ACCOUNT
   Value: (아래 단계 참고)

📝 설정 방법:

1. scripts/service-account.json 파일 열기

2. 전체 내용을 **한 줄로 압축** (공백 제거)

   방법 A - 온라인 도구 사용:
   https://codebeautify.org/jsonminifier

   방법 B - VS Code에서:
   - 전체 선택 (Ctrl+A)
   - 복사 (Ctrl+C)
   - 새 파일에 붙여넣기
   - 모든 줄바꿈 제거

3. 압축된 JSON을 Render 환경변수에 붙여넣기

예시 (압축 전):
{
  "type": "service_account",
  "project_id": "zero-club",
  "private_key_id": "...",
  ...
}

예시 (압축 후):
{"type":"service_account","project_id":"zero-club","private_key_id":"...",...}

⚠️ 주의:
- 작은따옴표 말고 큰따옴표 사용
- 줄바꿈 없이 한 줄로
- 앞뒤 공백 없이

   ✅ Firebase initialized with environment variable
